# 科研工作台项目 Agent 协作说明

本文说明项目内各类 Agent 的职责与协作入口。项目流程约束和正式日志规则以项目根目录 [`AGENTS.md`](../AGENTS.md) 及下列专项文档为准；旧流程仅作为[历史参考](20260913-旧版软件项目流程-历史参考.md)，不构成当前项目规则。

## 项目经理 Agent

负责澄清需求、维护需求范围与验收标准、审核实现是否符合需求和设计，并维护项目阶段汇报。

- 项目经理使用 `$pr-pm-01-project-manager-socratic-discovery` 执行苏格拉底式需求发现。
- [项目经理 Agent 使用说明](20260910-项目经理Agent-使用说明.md)
- 项目经理在正式编写或修订 SRS 时使用 `$pr-pm-02-project-manager`。
- 项目汇报、验收演示和需求链路报告使用 `$scienceresearch-pm-reporting`。

## 项目架构师 Agent

负责根据已确认需求维护系统架构、模块边界、接口、数据设计、迁移和设计追踪关系。架构与详细设计的正式成果按根级 `AGENTS.md` 归档到项目成效目录。

- [项目架构师 Agent 使用说明](20260910-项目架构师Agent-使用说明.md)

## 全栈工程师 Agent

负责按已确认的需求和设计实现、修复与回归验证，不自行扩大产品范围。实现前需明确文件落位和影响范围，测试及临时运行数据应置于隔离目录。

- [全栈工程师 Agent 使用说明](20260830-全栈工程师Agent-使用说明.md)

## 项目测试 Agent

负责使用隔离数据执行功能、HTTP、持久化和浏览器验证；发现缺陷后报告证据和未覆盖项，但不直接修改产品代码。

- [项目测试 Agent 使用说明](20260829-项目测试Agent-使用说明.md)

## 协作顺序

1. 项目经理澄清新需求，必要时更新需求文档和需求契约。
2. 架构师在需求确认后更新设计方案。
3. 工程师根据需求与设计实施并进行针对性回归。
4. 项目经理检查需求和设计符合性。
5. 测试 Agent 在隔离环境复验；发现阻断问题时回派工程师，直至问题闭环。

项目日志分别写入 `log/demand_log.md`、`log/pr-en-00-engineer_log.md` 和 `log/test_log.md`。版本发布仅在用户明确命令后执行，发布内容和校验信息保存在 `release/`。
