# 通用文档 HTML 呈现

## 1. 职责与触发

本 Skill 归属项目监理 `pr-ps-00-project-supervisor` 使用，用于把一份或多份已经存在、可读取、可追踪的文档源转换为**离线可打开、可导航、可审阅、可追溯**的 HTML 呈现层。它适用于项目手册、流程说明、需求/设计材料、治理记录、教学材料、报告、参考文档和跨文档知识门户。

触发条件：

- 用户要求把文档、手册、说明、报告、规格或参考资料呈现为 HTML；
- 用户要求把多份分散文档整合为一个文档门户；
- 用户要求为既有 HTML 增加导航、页内大纲、搜索、主题切换、打印或逻辑图；
- 用户要求把 DOCX/PDF 等文档内容转成可阅读 HTML，且已提供或批准可审计的文本提取路径；
- 已有 HTML 门户需要按新的批准范围或源文档更新。

非目标：

- 不替代源文档事实源；
- 不做未经登记的格式迁移、数据清洗或内容改写；
- 不生成产品业务代码、后端服务、数据库或部署流程；
- 不自动发布、部署、上传、提交或推送；
- 不把未确认的推断写成用户决定；
- 不复制参考网站的品牌、商标、专属文案或受保护视觉资产；
- 不因 HTML 生成成功而宣称源需求、实现、测试或研究结论已经验收。

## 2. 前置输入与登记

使用本 Skill 前必须完成项目监理登记，并确认：

1. **源文档清单**：每份输入的相对路径、格式、版本、日期、责任人和事实源状态；
2. **提取路径**：非纯文本源如何提取、由哪个工具/Skill 处理、提取结果放在哪里；
3. **呈现范围**：必须包含、明确排除和仅作背景的文档或章节；
4. **目标读者**：决策人、执行者、测试、审计、教学读者或混合读者；
5. **权威基线**：多版本并存时必须指定当前批准版本；
6. **输出落点**：按项目 `AGENTS.md` 和文档类型登记判断；
7. **格式参考**：只提取布局、导航、层级和交互模式，不复制品牌；
8. **权限边界**：是否允许读取外部参考网页、OCR、启动本地服务、保存浏览器证据；
9. **验收方式**：结构检查、静态扫描、项目治理校验器和真实浏览器检查。

若源文档不可读、提取路径未批准、呈现范围不清、目标路径无归属、需要覆盖归属不明文件或需要未授权外部访问，停止并登记阻塞。

## 3. 文档源处理矩阵

| 源类型 | 处理方式 | 最低要求 |
| --- | --- | --- |
| Markdown / 纯文本 | 直接解析标题、列表、表格、代码和链接 | 保留稳定 ID、命令、路径、状态和禁止项 |
| 既有 HTML | 解析后重建语义结构，不做原样注入 | 清理脚本、事件处理器、未知 iframe 和不可信样式；保留必要文本与可验证链接 |
| DOCX / Word | 先用批准的文档处理能力提取为 Markdown/纯文本 | 记录提取工具、源文件、页码/章节映射和丢失项 |
| PDF | 先用批准的 PDF 处理能力提取文本和必要表格 | 记录页码、扫描/文本型差异、OCR 不确定性和版面损失 |
| 表格 / 电子表格 | 只转换登记过的行列、摘要或图表数据 | 保留单位、口径、时间点和来源；不得虚构计算 |
| 演示文稿 | 按页或按主题提取标题、要点和说明 | 不把版式当作事实，不复制未授权图片 |
| 扫描件 / 图片 | 需要明确 OCR 授权 | 标注 OCR 置信度、不确定字符和人工复核需求 |
| 多文档混合 | 先统一为中间 Markdown/文本清单，再生成 HTML | 每个页面保留原来源和提取链路 |

提取产物属于运行证据或中间材料时，放入项目批准的隔离目录；正式 HTML 只引用经批准的相对路径。

## 4. 信息架构设计

先设计页面结构，再写完整样式：

1. **全局导航**：项目名、搜索、主题切换、打印和少量入口；
2. **分组导航**：按学习路径、文档类型、流程阶段或读者目标分组；
3. **正文页**：每份保留文档一个入口，包含眉题、标题、摘要、来源元数据和正文；
4. **页内大纲**：从当前页 `h2`/`h3` 生成，支持滚动高亮；
5. **搜索**：至少过滤文档标题和摘要，支持 `Ctrl+K` 聚焦；
6. **复制当前页**：复制当前活动页文本，失败时给出可见提示；
7. **移动导航**：侧栏在窄屏变为抽屉或折叠区，支持键盘和 `Escape` 关闭；
8. **来源追溯**：每页标明源文档相对路径、版本和提取方式，并声明“HTML 只是呈现层”。

默认输出为**单个离线 HTML 文件**。除非用户明确批准，不引入运行时 CDN、外部字体、后端 API、统计脚本或云资源。

## 5. 内容转换与安全规则

- 保留源文档中的稳定 ID、路径、接口名、状态名、命令、单位、日期和验收词；
- 长背景可选择性摘要，但不得删除 Must、禁止项、失败行为、权限边界和人工 Gate；
- 推断、重排和展示层归纳必须标注；
- 对源文本做 HTML 转义，防止把文档内容当作可执行 HTML；
- 既有 HTML 必须 sanitize：移除脚本、事件属性、`javascript:` URL、未知 iframe、远程 tracking 和不可信样式；
- 外部链接使用 `target="_blank"` 和 `rel="noopener noreferrer"`；
- 图片只在授权和有必要时使用，必须有替代文本、来源和尺寸约束；
- 表格保留表头、单位、口径和脚注，不得把排版表格误写成数据结论；
- OCR 或低置信提取内容标注不确定，未人工复核不得写成确认事实；
- 不写入机器绝对路径、秘密、真实日志、生产数据或未授权第三方内容；
- 源文档更新后，先更新事实源或提取记录，再同步 HTML。

## 6. 逐文档逻辑图

每份保留文档必须有与其职责对应的逻辑图或结构图。逻辑图放在页面元数据之后、正文之前。

最低要求：

- 使用语义 HTML 结构（如 `section`、`h2`、`ol`、`li`），不依赖外部图片；
- 每个节点有编号、短标题和一句职责说明；
- 节点之间有可见方向线或箭头；
- 图题说明来源和“展示层归纳”边界；
- 显示总步骤数或节点数，便于确认完整性；
- 有判断或回派时明确分支结果，例如 `PASS / FAIL / BLOCKED`、继续 / 阻塞 / 回派；
- 图必须与源文档职责一致，不得虚构流程、数据或决策。

图类型选择：

- 流程说明：纵向步骤流；
- 角色说明：输入 → 职责 → 输出 → 交回条件；
- 需求/设计：读者路径、模块关系或决策树；
- 教学手册：学习路径或概念模型；
- 报告：结论 → 证据 → 边界；
- 参考资料夹：来源分类 → 主题 → 使用方式。

## 7. 可访问性与响应式要求

必须实现：

- `lang` 与文档主语言一致，中文输出通常为 `lang="zh-CN"`；
- 语义标题层级和跳转到正文链接；
- 键盘可达的全局导航、侧栏、搜索、主题切换、打印和复制按钮；
- 可见焦点态；
- 文本和交互边界在浅色/深色主题下达到足够对比度；
- 1440、900、390、320 宽度无页面级横向滚动；
- 长路径、长表格和代码块在容器内换行或滚动，不撑破页面；
- 移动端隐藏无意义的 `Ctrl+K` 提示；
- 打印样式保留正文并隐藏操作控件；
- 动效克制，并支持减少动画偏好。

## 9. 验证流程

完成 HTML 后至少执行：

1. **结构检查**：
   - 保留页面数与登记范围一致；
   - 排除页面、导航项和可见排除文本不存在；
   - 每份保留文档有且仅有一个逻辑图/结构图；
   - 权威来源指向当前批准文档或提取记录。
2. **静态扫描**：
   - 无机器绝对路径、秘密、生产数据、运行时 CDN、不可信脚本和事件属性；
   - HTML 标签、本地引用和图片替代文本无明显错配。
3. **治理检查**：
   - 项目提供 F001 时必须运行并通过；
   - Skill 晋升场景运行 F002，但 F002 不自动安装。
4. **真实浏览器验证**：
   - 本地 HTTP 打开 HTML；如 Playwright 阻止 `file:` 协议，不得伪称 file 协议已验证；
   - 逐页点击导航，核对标题、hash、侧栏高亮和顶部入口；
   - 验证搜索、`Ctrl+K`、主题切换、复制本页、页内大纲和滚动高亮；
   - 检查 Console error、warning 和 PageError；
   - 保存 1440、900、390、320 截图，必要时保存深色和整页截图；
   - 尝试横向滚动后确认 `window.scrollX === 0`。
5. **视觉复核**：
   - 导航、层级、逻辑图、表格、代码块和长路径是否可读；
   - 无遮挡、截断、对比度不足或布局破碎；
   - 参考格式只保留通用模式，不复制品牌。
6. **提取复核**：
   - DOCX/PDF/OCR/表格提取结果与源文档抽查一致；
   - 页码、章节、单位、时间点和不确定项有记录。

验证证据必须写入隔离 `output` 目录，不得只口头报告。

## 10. 失败边界与阻塞

出现以下情况阻塞：

- 源文档缺失、不可读、冲突或未获呈现授权；
- 二进制文档没有批准、可审计的提取路径；
- OCR 结果低置信且没有人工复核；
- 输出目录无法确定或目标文件已存在且归属不明；
- 用户要求删除源文档或历史治理证据；
- 需要引入外部运行时依赖但未获批准；
- 需要复制第三方品牌或受保护内容；
- HTML 无法在浏览器中打开或 Console 出现未处置错误；
- 响应式、键盘或可访问性检查失败；
- 项目治理校验器出现错误；
- 需要提交、推送、部署、发布或写入外部系统但未获授权。

阻塞时记录原因、已尝试动作、所需决策和回滚状态。

## 11. 权限、幂等与并发

- 本 Skill 只新增或更新已登记的 HTML 呈现层、批准的提取中间产物和对应治理记录；
- 不覆盖无关文件；同名冲突时先检查归属，不直接改写；
- 重新生成必须保留最新批准范围和逻辑图；
- 临时生成脚本放系统临时目录或隔离 run 目录，结束前清理；
- 浏览器证据写入项目 `output` 的独立 run-id 目录；
- 本地 HTTP 服务验证后必须关闭；
- 不自动提交、推送、发布、删除、读取凭据或写入外部系统。

## 12. 维护与演化

- 维护人：项目监理；
- 使用角色：`pr-ps-00-project-supervisor`；
- 生命周期：候选 → 项目试点 → 独立评审 → 人工批准 → 启用 → 监控 → 优化/合并/淘汰；
- 试点指标：源文档覆盖完整、提取链路可追溯、逐页逻辑图准确、验证证据齐全、用户返工减少；
- 演化触发：同类文档 HTML 任务重复出现、用户多次要求同类修正、现有说明无法覆盖新文档类型；
- 全局晋升必须另行提供试点、独立评审、安全扫描、版本/哈希、人工批准、安装记录和回滚证据，本 Skill 不自动晋升。

## 13. 交付报告

完成后报告：

- HTML 相对路径和保留文档清单；
- 源格式、提取路径和版本；
- 排除项与原因；
- 每页逻辑图/结构图覆盖情况；
- 治理校验器和浏览器验证结果；
- 截图/trace/提取复核证据路径；
- 未执行项、残余风险和下一步；
- 明确声明 HTML 不是源文档事实源，验证通过不等于正式验收。
