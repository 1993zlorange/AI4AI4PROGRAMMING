# Skill晋升审计器 API 说明

## 1. 概述

- 源文件：`projectname/project/scripts/f002_skill_promotion_audit.py`
- 用途与非目标：只读审计项目 Skill 从试点到全局晋升所需的项目 Skill、提案、试点、独立评审、安全扫描、人工批准、全局安装记录、回滚和哈希；绝不安装、复制、修改或删除全局 Skill。
- 运行环境和依赖：Python 3.11+ 标准库；根级 `AGENTS.md` 配置；JSON 兼容的 `config/skill-promotion.yaml`。

## 2. 调用方式

```text
python projectname/project/scripts/f002_skill_promotion_audit.py --project-root . --check
```

## 3. 参数

| 参数 | 类型 | 必填 | 默认值 | 约束 | 说明 |
|---|---|---|---|---|---|
| `--project-root` | Path | 是 | 无 | 必须含根级 `AGENTS.md` | 项目模板根目录 |
| `--check` | flag | 否 | false | 只读统一入口 | 执行审计 |

## 4. 输入、输出与退出码

| 对象/退出码 | 契约 | 示例 | 失败行为 |
|---|---|---|---|
| 输入 | Skill 晋升登记和项目内相对证据引用 | `promotions: []` | 缺失或越界引用输出 `ERROR` |
| 标准输出 | 每个错误一行 `ERROR`，最后汇总 | 无候选时输出 `INFO` | 不产生写入 |
| 退出码 `0` | 无错误 | 无候选 Skill 或完整证据链 | 无 |
| 退出码 `1` | 证据、模板、名称或哈希不一致 | 缺少批准或项目 Skill | 阻断晋升和质量门关闭 |
| 退出码 `2` | 项目根不存在 | 参数错误 | 修正显式路径后重试 |

## 5. 安全、幂等与并发

- 写入/删除/联网/凭据权限：完全只读；不联网、不读取凭据、不触发安装或发布。
- 路径边界：证据引用只能位于项目根内；Markdown 锚点允许但文件本身必须存在。
- 重复执行和冲突：重复运行只重算当前证据和项目 Skill 文件树哈希。
- 中断、恢复和回滚：无持久副作用；修正证据或登记后重新审计。

## 6. 验证与兼容性

- 测试/试运行命令：`python -m py_compile projectname/project/scripts/f002_skill_promotion_audit.py`；`python projectname/project/scripts/f002_skill_promotion_audit.py --project-root . --check`；`python -m unittest discover -s projectname/project/tests -p test_f002_skill_promotion_audit.py -v`。
- 证据：同批 `20260913-AI4PROGRAMMING治理优化实施-质量门禁.md`。
- 版本兼容：当前为 AI4PROGRAMMING 模板 v1 配置；晋升字段变化必须同步修改登记、脚本、API 说明和回归测试。
- 已知限制：哈希和文件存在只能证明证据链完整，不等同于安全结论、独立评审结论或用户批准；无候选 Skill 不代表全局能力已安装。
