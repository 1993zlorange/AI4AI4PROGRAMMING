# 项目治理校验器 API 说明

## 1. 概述

- 源文件：`projectname/project/scripts/f001_governance_validate.py`
- 用途与非目标：只读检查功能三元组、实现/测试路径、工程顶层目录、日期化管理文档和项目级文档型 Skill 模板链路；不创建、移动、删除、安装、发布或修复任何内容。
- 运行环境和依赖：Python 3.11+ 标准库；根级 `AGENTS.md` 的 `project-supervision` 配置；JSON 兼容的 `config/feature-registry.yaml`。

## 2. 调用方式

```text
python projectname/project/scripts/f001_governance_validate.py --project-root . --check
```

## 3. 参数

| 参数 | 类型 | 必填 | 默认值 | 约束 | 说明 |
|---|---|---|---|---|---|
| `--project-root` | Path | 是 | 无 | 必须含根级 `AGENTS.md` | 项目模板根目录 |
| `--check` | flag | 否 | false | 只读统一入口 | 执行校验 |

## 4. 输入、输出与退出码

| 对象/退出码 | 契约 | 示例 | 失败行为 |
|---|---|---|---|
| 输入 | 根级治理配置、功能登记、工程目录、项目管理文档、项目 Skill | `feature_id=F001` | 配置或登记不可读时输出 `ERROR` |
| 标准输出 | 每个错误一行 `ERROR`，最后汇总 | `F001 治理校验完成：ERROR=0` | 不产生写入 |
| 退出码 `0` | 无错误 | 当前模板基线 | 无 |
| 退出码 `1` | 存在治理错误 | 未登记功能文件、路径不存在或模板缺失 | 阻断当前质量门关闭 |
| 退出码 `2` | 项目根不存在 | 参数错误 | 修正显式路径后重试 |

## 5. 安全、幂等与并发

- 写入/删除/联网/凭据权限：完全只读；不联网、不读取凭据、不调用外部服务。
- 路径边界：所有配置和登记路径必须解析到 `--project-root` 内；工程路径必须位于 `engineering_root` 内。
- 重复执行和冲突：重复运行结果由当前文件状态决定；不占锁、不修改文件。
- 中断、恢复和回滚：无持久副作用；修正被检查资产后可重新执行。
