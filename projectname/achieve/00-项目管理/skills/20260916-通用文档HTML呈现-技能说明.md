# ps-10-document-html-presentation 通用文档HTML呈现技能说明

## 1. 用途与归属

本 Skill 归项目监理 `pr-ps-00-project-supervisor` 使用，用于把已登记的 Markdown、纯文本、既有 HTML 或经批准提取的 DOCX/PDF 等文档源，转换为离线 HTML 文档门户。它强调呈现范围受控、源文档和提取记录仍是事实源、每份保留文档有逻辑图或结构图、输出可离线打开、验证证据可审计。

## 2. 调用方式

```text
由 pr-ps-00-project-supervisor 使用 $ps-10-document-html-presentation，
将以下已登记文档源转换为离线 HTML 文档门户：
<源文档相对路径清单>
源格式与提取路径：<Markdown / 纯文本 / 既有HTML / DOCX提取 / PDF提取 / OCR等>
呈现范围：<必须包含 / 必须排除 / 背景参考>
权威基线：<当前批准文档或提取记录>
目标读者：<决策人 / 执行者 / 测试 / 审计 / 教学读者>
输出落点：<按 AGENTS.md 判断的目录>
验证要求：结构检查、静态扫描、F001、Playwright 1440/900/390/320、Console/PageError、逐页逻辑图。
```

## 3. 输入契约

| 输入 | 要求 |
| --- | --- |
| 源文档 | 路径存在、格式明确、版本和责任人明确 |
| 提取路径 | DOCX/PDF/OCR/表格必须有批准工具、中间产物和映射记录 |
| 呈现范围 | 包含、排除和背景项逐条登记 |
| 权威基线 | 多版本并存时指定当前批准版本 |
| 目标读者 | 决定信息密度、摘要层级和导航组织 |
| 输出落点 | 由项目 `AGENTS.md` 和文档类型登记确定 |
| 格式参考 | 只借鉴布局模式，不复制品牌和受保护内容 |
| 验证命令 | 至少包含项目治理校验器和真实浏览器检查 |

## 4. 输出契约

| 输出 | 落点 | 说明 |
| --- | --- | --- |
| HTML 文档门户 | 项目批准的成效/交付/管理目录 | 单文件、离线、语义化、响应式、可搜索 |
| 逐文档逻辑图/结构图 | HTML 内 | 每份保留文档一张，节点、方向、步骤数和来源边界明确 |
| 提取中间产物 | 批准的隔离 output/run-id 目录 | 仅保存必要、可审计的提取结果 |
| 浏览器证据 | `projectname/project/output/playwright/<run-id>/` | 截图、Console、DOM 检查和验证结果 |
| 治理记录 | `projectname/achieve/00-项目管理/` | 需求、监督、日志、质量、变更、成本 |
| 交付说明 | 会话报告 | 范围、源格式、验证、未执行项、风险和下一步 |

## 5. 标准流程

1. 项目监理登记需求、范围、路径、权限、风险和验收；
2. 读取源文档、项目规则、既有文档类型、提取记录和参考格式；
3. 按源类型执行直接解析或批准提取，形成可审计文本/Markdown；
4. 设计信息架构：全局导航、分组侧栏、正文、页内大纲、搜索、主题和复制；
5. 为每份保留文档设计逻辑图或结构图；
6. 从中文空白 HTML 模板生成输出；
7. 转换内容时保留稳定 ID、命令、边界和验收词，标明推断和 OCR 不确定性；
8. 执行静态扫描、来源抽查和 F001；
9. 启动本地 HTTP 服务，用 Playwright 验证页面、交互、Console 和多视口；
10. 保存隔离证据并关闭服务/浏览器；
11. 写入日志、质量、变更、成本并关闭监督记录。

## 6. 验证清单

- 保留页面与登记范围一致；
- 排除项在 DOM 和可见正文中不存在；
- 每份保留文档有逻辑图/结构图；
- 权威来源指向当前批准文档或提取记录；
- DOCX/PDF/OCR 提取结果与源文档抽查一致；
- 无运行时 CDN、机器绝对路径、秘密、生产数据、不可信脚本和事件属性；
- F001 通过；
- Console errors / warnings / PageError 为 0；
- 1440、900、390、320 宽度页面横向滚动为 0；
- 导航、搜索、`Ctrl+K`、主题、复制、页内大纲和滚动高亮可用；
- 证据已保存并清理临时产物。

## 7. 失败与回滚

失败时不得交付“已完成”。记录阻塞原因、已验证项、未验证项和所需决策。

回滚方式：

- 删除或替换本次 HTML 呈现层；
- 保留提取记录和治理记录用于审计；
- 不删除源文档和历史证据；
- 如需恢复上一 HTML，必须确认旧版本仍符合当前批准范围；
- Skill 可回退到 v0.1.0，但需登记变更和原因。
