# ps-10-document-html-presentation 项目监理文档HTML呈现技能说明

## 1. 用途与归属

本 Skill 归项目监理 `pr-ps-00-project-supervisor` 使用，用于把已登记的 Markdown 项目文档转换为离线 HTML 文档门户。它强调呈现范围受控、Markdown 仍是事实源、每份保留文档有逻辑图、输出可离线打开、验证证据可审计。

## 2. 调用方式

在项目监理完成需求登记后显式调用：

```text
由 pr-ps-00-project-supervisor 使用 $ps-10-document-html-presentation，
将以下已登记 Markdown 文档转换为离线 HTML 文档门户：
<源文档相对路径清单>
呈现范围：<必须包含 / 必须排除 / 背景参考>
主流程基线：<当前批准文档>
输出落点：<按 AGENTS.md 判断的目录>
验证要求：F001、静态扫描、Playwright 1440/900/390/320、Console/PageError、逐页逻辑图。
```

## 3. 输入契约

| 输入 | 要求 |
| --- | --- |
| 源 Markdown | 路径存在、内容可读、来源和版本明确 |
| 呈现范围 | 包含、排除和背景项逐条登记 |
| 主流程基线 | 多版本并存时必须指定当前批准版本 |
| 目标读者 | 决定信息密度、摘要层级和导航组织 |
| 输出落点 | 由项目 `AGENTS.md` 和文档类型登记确定 |
| 格式参考 | 只借鉴布局模式，不复制品牌和受保护内容 |
| 验证命令 | 至少包含 F001 和真实浏览器检查 |

## 4. 输出契约

| 输出 | 落点 | 说明 |
| --- | --- | --- |
| HTML 文档门户 | 项目批准的成效/交付/管理目录 | 单文件、离线、语义化、响应式、可搜索 |
| 逐文档逻辑图 | HTML 内 | 每份保留文档一张，节点、方向、步骤数和来源边界明确 |
| 浏览器证据 | `projectname/project/output/playwright/<run-id>/` | 截图、Console、DOM 检查和验证结果 |
| 治理记录 | `projectname/achieve/00-项目管理/` | 需求、监督、日志、质量、变更、成本 |
| 交付说明 | 会话报告 | 范围、验证、未执行项、风险和下一步 |

## 5. 标准流程

1. 项目监理登记需求、范围、路径、权限、风险和验收；
2. 读取源 Markdown、项目规则、既有文档类型和参考格式；
3. 设计信息架构：全局导航、分组侧栏、正文、页内大纲、搜索、主题和复制；
4. 为每份保留文档设计职责逻辑图；
5. 从中文空白 HTML 模板生成输出；
6. 转换内容时保留稳定 ID、命令、边界和验收词，标明推断；
7. 执行静态扫描和 F001；
8. 启动本地 HTTP 服务，用 Playwright 验证页面、交互、Console 和多视口；
9. 保存隔离证据并关闭服务/浏览器；
10. 写入日志、质量、变更、成本并关闭监督记录。

## 6. 验证清单

- 保留页面与登记范围一致；
- 排除项在 DOM 和可见正文中不存在；
- 每份保留文档有逻辑图；
- 主流程来源指向当前批准 Markdown；
- 无运行时 CDN、机器绝对路径、秘密和生产数据；
- F001 通过；
- Console errors / warnings / PageError 为 0；
- 1440、900、390、320 宽度页面横向滚动为 0；
- 导航、搜索、`Ctrl+K`、主题、复制、页内大纲和滚动高亮可用；
- 证据已保存并清理临时产物。

## 7. 失败与回滚

失败时不得交付“已完成”。记录阻塞原因、已验证项、未验证项和所需决策。

回滚方式：

- 删除或替换本次 HTML 呈现层；
- 保留治理记录用于审计；
- 不删除源 Markdown 和历史证据；
- 如需恢复上一 HTML，必须确认旧版本仍符合当前批准范围。

## 8. 生命周期
