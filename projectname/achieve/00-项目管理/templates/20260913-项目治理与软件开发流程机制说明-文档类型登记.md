# 项目治理与专业流程机制说明文档类型登记

## 1. 类型定义

| 字段 | 规则 |
| --- | --- |
| 文档类型 | 项目治理与专业流程机制说明 |
| 用途 | 解释项目治理配置、记录机制、命名、文件归属、Agent 协作、专业流程、质量门和结论边界 |
| 负责人 | 项目监理与适用专业负责人 |
| 命名 | `YYYYMMDD-内容简述-机制说明.md` |
| 正式落点 | 项目管理根目录的 `supervision/` |
| 中文空白模板 | 同级 `templates/` 中日期化机制说明模板 |
| 保留/归档 | 版本化保留，不覆盖历史版本 |
| 敏感性 | 不记录凭据、秘密、生产数据或机器绝对路径 |

## 2. 必备结构

- 元数据、范围、非目标、治理基线和状态；
- 有效规则入口、配置、路径和角色边界；
- 需求、日志、反思、命名、归属和新能力生成机制；
- 专业流程图、质量门、人工决定和失败边界；
- 证据、限制、残余风险、下一步和变更记录。

## 3. 验证规则

- 路径和规则来自当前项目，不写死机器路径；
- 模板只提供中文结构，不含具体项目事实或参考文档名称；
- 实施、测试、发布和验收状态分别报告；
- 未执行检查和待人工决定事项明确保留；
- 正式文档通过相对路径链接需求、监督、日志、质量和变更记录。
