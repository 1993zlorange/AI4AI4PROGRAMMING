# 项目流程HTML页面登记

| 项目 | 内容 |
|---|---|
| 文档类型名称 | 项目流程/文档门户 HTML 页面 |
| 目的 / 非目标 | 目标：以离线单文件 HTML 呈现一份主流程说明和多份参考文档，提供导航、页内大纲、搜索、主题切换和响应式阅读体验。非目标：不作为 Web 应用产品功能，不替代 Markdown 事实源，不包含真实数据或外部服务依赖 |
| 负责人 / 评审人 | 全栈设计工程师负责生成；项目监理负责命名、归属和验证记录；用户负责是否采用 |
| 扩展名与命名模式 | `YYYYMMDD-内容简述-流程说明.html`；同类输出可使用 `YYYYMMDD-内容简述-文档门户.html` |
| 项目内目录 | `projectname/achieve/04-交付与阶段/`；空白模板在 `projectname/achieve/00-项目管理/templates/` |
| 适用 Skill | 本地 `$pr-en-01-fullstack-design-engineer` 的前端设计与浏览器验证原则；参考外部 `spec-to-readable-html` 与 `writing-web-documentation` Skill 的只读调研结论；使用 `$playwright` 验证 |
| 中文空白模板路径 | `../templates/20260916-项目流程HTML页面-模板.html` |
| 必填结构/字段 | `lang="zh-CN"`、页面标题、生成日期、来源列表、全局导航、左侧文档导航、正文区、页内大纲、来源追溯、可访问性标记、打印样式、无外部依赖声明 |
| 证据与追溯 | 页面引用源 Markdown 相对路径；浏览器截图、Console/PageError 检查和多视口证据保存到 `projectname/project/output/playwright/<run-id>/`；治理记录互相链接 |
| 敏感性与权限 | 不包含秘密、真实日志、生产数据、机器绝对路径或未授权第三方品牌资产；只读取公开网页 |
| 保留、归档和清理 | 正式 HTML 随交付材料版本化保留；浏览器证据按项目 run-id 保留；生成期临时文件不得放入项目根 |
| 验证方法 | Playwright 本地打开；检查 1440/900/390 宽度、导航切换、键盘焦点、主题切换、Console/PageError、横向溢出和内容入口；F001 只读检查 |
| 变更规则 | 内容变化先修改 Markdown 事实源，再同步 HTML；版式变化记录版本和验证证据，不允许 HTML 成为唯一事实源 |

## 决定记录

- 与现有类型的重叠：与 Markdown 流程说明配套，不替代 Markdown；与正式 Web 产品页面不同，不进入 `apps/` 或 `packages/`。
- 试点：`projectname/achieve/04-交付与阶段/20260916-软件项目Agent协作-流程说明.html`。
- 人工决定：待用户审阅；批准后可作为同类项目文档 HTML 模板。
