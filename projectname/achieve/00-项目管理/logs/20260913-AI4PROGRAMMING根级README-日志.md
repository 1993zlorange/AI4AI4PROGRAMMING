- 为什么做（why）：用户要求按成熟开源项目的可读性标准，为模板提供根级入口说明。
- 预期影响（expected_impact）：派生项目维护者可快速定位模板用途、边界、启动步骤和权威规则，减少误把占位内容当已实现产品的风险。

- 受影响需求（affected_requirements）：DOC-README-01、DOC-README-02。
- 受影响文件（affected_files）：`README.md` 及本批项目管理记录。
- 受影响下游（affected_downstream）：新项目初始化、贡献者入门、Agent 调用、质量和发布理解。
- 决策依据（decision_basis）：用户明确请求；根级 AGENTS 要求项目入口说明与治理、目录和质量规则一致。
